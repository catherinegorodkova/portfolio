# Catherine Gorodkova — portfolio site

Static site. One `index.html`, media in `media/`.

- `media/home/` — hero, selected-work trio, showreel, fashion band
- `media/work/<slug>/` — project images (`01.jpg`, `02.jpg`, …), cover is `cover.jpg`, hover is `hover.jpg`
- `media/press/` — press screenshots

Deployed on Vercel from the `main` branch. Any push updates the live site.
